# 📊 Indicador de Pagamentos e Conciliação Diária

Dashboard desenvolvido em HTML, CSS e JavaScript para automatizar a visualização e o controle de status de operações de tesouraria. 

## 🎯 Objetivo do Projeto
Transformar dados brutos de relatórios de pagamentos em insights rápidos de negócio. A ferramenta permite que a área financeira faça a leitura de grandes volumes de linhas sem depender de planilhas pesadas, automatizando a contagem de volume financeiro diário e o monitoramento de gargalos em aprovações.

## 🛠️ Tecnologias e Funcionalidades
- **Linguagens:** HTML5, CSS3, JavaScript.
- **Processamento Local:** Utiliza a biblioteca `SheetJS` para ler os arquivos `.xlsx` inteiramente no navegador do usuário, garantindo segurança e privacidade dos dados financeiros (Zero upload para servidores externos).
- **Regras de Negócio Aplicadas:** Identificação visual de status de esteira (ex: "Envio de Comprovante", "Em Conferência") e somatória dinâmica de volume processado.
